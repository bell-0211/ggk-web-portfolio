## 作品集证明什么

- **AI 原生产品思维** — 把「微信小程序 AI 助手 + 远程终端协同 + 芯片手册垂类知识 + token 商业化」整合成一个清晰的信息架构与落地页；
- **用 AI 工具链独立交付** — 从产品意图到可运行 Demo，用一套 AI 编码工作流实现无需构建步骤的完整单页产品（HTML/CSS/JS）；
- **可交互原型工程** — 状态机驱动的「手机↔终端协同」演示、小程序自动演示、3D Hero、全站中英国际化；
- **可执行证据，而非只有截图** — Demo 直接入库可打开，脚本与测试校验资源路径、i18n 键覆盖与脱敏。

> 这是公开脱敏版作品集。内置落地页 Demo 为**演示目的合成的占位产品**，不含生产数据、真实用户指标、密钥或雇主保密信息。

## 快速运行

校验脚本需要 Python 3.10+；Demo 本身无任何依赖。

```bash
# 1) 打开可运行 Demo
cd demo/web && python -m http.server 8000    # 浏览器访问 http://localhost:8000

# 2) 校验入库 Demo（路径 + i18n + 脱敏）
cd ../..
python scripts/validate_assets.py

# 3) 对 Demo 做确定性结构冒烟测试
python scripts/run_demo.py

# 4) 运行回归测试
python -m unittest discover -s tests -v
```

这些检查均为离线、确定性执行，用于验证入库 Demo 内部自洽且干净；它们不是真实产品或线上模型的 Benchmark。
